Request and response types

Top-level JSON messages use a type discriminator. The names below are case-sensitive. A refused application request can return error with a code and message. A transport failure may leave the caller without a response. For example, {"type":"serverSource"} asks a configured Home to return its sourceUrl and revision.

Events and feeds

Signed events and deletion

feed
Read a community projection with a member token and optional nearby filter. Returns feed.
submit
Submit a device-signed event with membership and any account chain. A receipt names the accepted ID. Returns accepted.
pull
An authenticated peer reads a bounded page in its authorized scopes, with generation and next cursor. Returns page.

Accounts

Accounts and recovery

accountLookup
Read the account chain known to this Home using community membership. Returns accountState.
accountRegister
Verify the root-signed chain and active device proof before registering the account revision. Returns accountState.
accountExport
Read a page of the owner’s accepted envelopes using membership and device proof. Returns ownedEvents.
accountImport
Verify and save a batch of owned envelopes into private personal history. Returns personalImported.
announceAccount
Advance an already known account using its signed chain after a move or revocation. Returns accountState.

Public groups and discovery

Public groups

directory
Exchange signed descriptors, host permits and address leases. Returns directory.
enrollHost
Ask the group authority to admit the authenticated connecting endpoint as a host. Returns hostPermit.
groups
List group summaries known to the member’s Home. Returns groups.
createGroup
Create a signed descriptor and receive the group summary and join configuration. Returns groupJoined.
joinGroup
Join through the member’s Home, enrolling the Home as a host if needed. Returns groupJoined.

Authenticated member operations

Encrypted messages

social
Use a member token and an account-device proof for one of the social operations below. Returns social / feed.
privateGroup
Run a roster or ciphertext operation with separate private-group authorization. Returns privateGroup.

Profiles, projections and takeover

Replicas, standby and backups

peerProfiles
Fetch newer revisions from an authorized origin for named authors in a shared community. Returns social.
pullPublicProjection
A trusted replica conditionally requests the founding Home’s moderated public snapshot. Returns publicReplicaFeed / projectionUnchanged.
publicReplicaFeed
Fetch a configured public snapshot by community, including its as-of time. Returns publicReplicaFeed.
homeOperation
An HA worker accepts a retryable wrapped request and returns the committed inner response. Returns Inner call result.

Reports and source

Privacy and reporting

reportAvailability
Check whether the enrolled primary accepts reports. Returns reportAvailable.
submitReport
Use membership and a private receipt to submit selected evidence to that primary. Returns reportResult.
reportStatus
Present the private receipt to check a case disposition. Returns reportResult.
serverSource
Ask a configured build for its published source archive URL and revision. Returns serverSource.

Social operations

A social request carries a community token, account, device proof and an op tagged by kind. The two feed operations return feed. The others return social with an operation-specific result.

Personalized reads and identity

Feeds, profiles and names

feed
Return the account’s personalized feed.
privacyFeed
Include per-item visibility metadata for privacy-aware clients.
setProfile
Save profile fields against an expected revision.
profiles
Resolve accessible named event references into current profiles.
claimUsername
Reserve the account’s local name on a Home with a username domain.
privacyStatus
Read preferences, profile, request and notification state.
setPrivacy
Update visibility, approval and age preferences.

Blocks and encrypted mail

Encrypted messages

contact
Resolve a named event into a messaging contact and signed source event.
block
Block by account or event ID.
unblock
Remove an existing block using its list identifier.
blocks
Fetch the account’s block list.
approve
Approve a sender and release held mail.
dismissRequest
Discard held packets from a sender.
publish
Register signed messaging prekeys.
claim
Claim a peer’s signed prekey for a new session.
deliver
Submit a signed ciphertext letter.
inbox
Fetch encrypted mail after the saved cursor and acknowledge earlier deliveries.

Activity and push

Inbox and notifications

notificationInbox
Read grouped replies, messages and held requests.
notificationThread
Resolve a thread and anchor under current visibility rules.
readNotification
Advance the read position for a category and target.
muteNotifications
Set or clear a thread notification mute.
setPush
Set the installation’s provider subscription and categories.

Private group operations

A privateGroup request carries its own proof and a kind-tagged operation. The response contains a tagged result.

Room, roster and history

Private groups

create
Store a signed room and initial roster. Returns saved.
roster
Fetch the signed roster history. Returns roster.
change
Submit an owner-signed roster revision and join request when required. Returns saved.
publish
Submit a signed encrypted event and, when needed, a session record. Returns accepted.
read
Read a page for the named group and roster with an optional history cursor. Returns page.

HA control exchange

The authorized workers and ledger exchange internal control messages. Seed initializes the authority. Open identifies an operation and known revision. Ready grants a permit, or Committed returns a previous result. Commit presents the permit and result for the staged revision. The authority can also return Seeded, Busy or Refused.
