Getting connected

  • How a post travels

    Follow one book-swap invitation from signing to deletion.

  • Connecting to a Home

    Before your device can fetch a feed, it needs to know which Home to call and which community it can enter.

  • Accounts and recovery

    A person can change devices or move Homes while keeping the same account public key.

Public conversations

  • Signed events and deletion

    A post has a stable ID even after its text is erased. That lets a peer verify both the original publication and the author’s decision to delete it.

  • Feeds, profiles and names

    A feed brings together signed posts, replies and votes with the profile details and visibility rules that apply when someone reads it.

  • Trust between Homes

    Two Homes can share a community while keeping independent membership and moderation policies.

  • Public groups

    A city book club and a worldwide reading group can each have a stable identity and a community feed hosted by several Homes.

Private conversations

  • Private groups

    An encrypted group on one Home admits individual devices. The owner’s signed membership list determines which devices receive keys for future posts.

  • Encrypted messages

    Two named accounts on the same Home can exchange messages while one of them is offline.

  • Inbox and notifications

    Yap’s activity inbox tracks replies, encrypted mail and message requests. Each installation chooses which kinds of alerts to receive.

Operating a Home

  • Privacy and reporting

    A local hide, an account block, a signed deletion and a safety report each reach a different audience.

  • Replicas, standby and backups

    A Home can publish a read-only fallback feed or authorize a second server to handle private operations for the same logical identity.
